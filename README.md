## 📲 Install

1. Open **SkyStream** → **Settings** → **Manage Extensions** → **Add Repository**.
2. Type the shortcut code **`tjplugins`**, or paste this link:

   ```
   https://raw.githubusercontent.com/Skywave22/TJ-Plugins/main/repo.json
   ```

3. Install the plugins you want.
4. On the Home screen, tap the **Provider** button (bottom right) and pick a plugin.

**Updating:** open **Extensions** and tap **Update**. New versions show up a few minutes after they are published.

## ⭐ All-in-one

**Can't decide which plugin to open? Install All-in-one.** It has 24 of the plugins below built in (everything except ReelFren) and combines them:

| | |
|---|---|
| 🏠 **One home page** | Trending, Latest Movies and Series, Hindi, Hindi Dubbed, Netflix, Prime, K-Drama, Anime, Hindi Serials and more, filled from every site. The same title from different sites is one card. |
| 🔎 **One search** | Searches all 24 sites at once (about 2 seconds) and merges the results. |
| ▶️ **Every link** | When you press Play, it finds the same movie or episode on **every site that has it** and lists all working links together, 1080p and Hindi first. A popular movie often gets 50 to 70 links from 10+ sites. Collecting them takes 10 to 40 seconds. |

| **All-in-one** 🆕 | v1 | All of the sites below in one plugin | hi, en, ta, te, ml, ko, ja, ur |

All-in-one updates itself whenever one of the plugins inside it is updated.

## 🛡️ A plugin only works with a VPN?

Many internet providers block streaming sites, usually by giving a fake DNS answer for the site's name. Try these in order:

1. **Private DNS (Android, best option):** **Settings → Network & internet → Private DNS** → enter `dns.google` or `one.one.one.one`. This also covers the video player. On iPhone, use the Cloudflare **1.1.1.1** app.
2. **SkyStream's DNS:** **Settings → Accounts, Network & Downloads → DNS over HTTPS → On**.
3. **Another domain:** if a plugin shows a ⚙️ gear in Extensions, pick another domain there.
4. **VPN:** if a site is blocked completely, only a VPN helps.

The plugins also try to work around blocks on their own:
- **Mirror failover:** a blocked domain is retried on the site's other known domains.
- **Geo-pass relay (optional):** blocked pages can be loaded through a free Cloudflare Worker. To set it up, see [relay/README.md](relay/README.md).
- **Clear messages:** you see *"… is blocked on your network"* or *"not responding, try again"* instead of an empty screen.

## ❓ Good to know

- **Links are checked first.** Dead links are hidden before the server list is shown, and the best quality and Hindi audio come first where there is a choice.
- **Sites change.** If a plugin suddenly shows nothing, the site has usually moved or is down. Check for an update in Extensions.
- **ReelFren:** a few apps (MovieBox, JoyReels, FlexTV, KalosTV, Vigloo) are currently not playing on reelfren.com itself, so the plugin says so instead of showing a broken video.
- **DesiSerials:** each show lists its latest 180 episodes. Video hosts delete old files, so shows that ended before 2025 often won't play.
- **RareAnimes:** some older posts only have Mega links, which can't be streamed.
- **GDFlix / HubCloud** files (KatMovieHD, SSR Movies, KDramaMaza, PikaHD, KatDrama, Movies4u) play in the app. Desktop test tools may get a Cloudflare check on them.

Release notes for every version are in **[CHANGELOG.md](CHANGELOG.md)**.

## 🛠️ For developers

```
<Plugin>/plugin.json   manifest: name, version, baseUrl, domains, authors
<Plugin>/plugin.js     the plugin (getHome, search, load, loadStreams)
AllInOne/              generated by tools/build-aio.mjs from the other plugins (don't edit by hand)
tools/aio/core.js      the All-in-one merging layer (home rows, search, link collection)
tools/                 test harness, net-guard snippet, helper scripts
relay/                 optional geo-pass Cloudflare Worker
dist/                  built by CI; don't edit by hand
```

```bash
npm i -g skystream-cli
skystream validate                                   # check every manifest and plugin
skystream test -p ReelFren -f search -q "billionaire"
cd tools && npm install && node app-harness.mjs ../ReelFren --auto --items 3
```

Pushing to `main` runs GitHub Actions, which rebuilds All-in-one (`node tools/build-aio.mjs`, which bumps its version when any plugin changed), then `dist/plugins.json` and the plugin bundles. Bump `version` in `plugin.json` so the app offers the update.
