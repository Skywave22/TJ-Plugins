## Install

**1.** Open **SkyStream** → **Settings** → **Manage Extensions** → **Add Repository**

**2.** Enter the shortcut code **`tjplugins`**, or paste this URL:

```txt
https://raw.githubusercontent.com/Skywave22/TJ-Plugins/main/repo.json
```

**3.** Install the plugins you want, then tap the **Provider** button on the Home screen to switch between them.

> **Updating:** open **Extensions** → **Update**. New versions appear a few minutes after they are published.

## ⭐ All-in-one

**Install this if you only want one plugin.** It embeds **28 of the 30 plugins** below (all except ReelFren and HiStream, whose servers are already inside it through ScreenScape) and behaves like a single, very well-stocked source.

| | |
|---|---|
| **One home page** | Trending, Latest, Hindi, Hindi Dubbed, Netflix, Prime, K-Drama, Anime and more — merged from every site, with duplicate titles shown as one card. |
| **One search** | Searches every embedded site at once in about 2 seconds. |
| **Every link** | Press Play and it finds the same title on every site that has it, then lists all working links together — 1080p and Hindi first. Popular movies often get **50–70 links from 10+ sites**. |

All-in-one rebuilds itself automatically whenever any plugin inside it is updated.

## 🛡️ Only on a VPN?

Many internet providers block streaming sites by returning a fake DNS answer. Try these in order:

| Step | What to do |
|:-:|---|
| **1** | **Private DNS** (Android): Settings → Network & internet → Private DNS → `dns.google` or `one.one.one.one`. On iPhone, use the Cloudflare **1.1.1.1** app. |
| **2** | **SkyStream DNS**: Settings → Accounts, Network & Downloads → **DNS over HTTPS** → On. |
| **3** | **Another domain**: if a plugin shows a ⚙️ gear in Extensions, pick a different domain there. |
| **4** | **VPN**: if the site itself is blocked, only a VPN will help. |

The plugins also work around blocks by themselves:

- **Mirror failover** — a blocked domain is retried on the site's other known domains.
- **Geo-pass relay** *(optional)* — blocked pages can be loaded through a free Cloudflare Worker: see [relay/README.md](relay/README.md).
- **Clear messages** — you get *"… is blocked on your network"* or *"not responding, try again"* instead of an empty screen.

## 💡 Good to know

- **Links are checked first.** Dead links are hidden before the server list appears, and the best quality and Hindi audio come first where there is a choice.
- **Sites move.** If a plugin suddenly shows nothing, the site has usually changed domain or is down — check for an update in Extensions.
- **CineFreak** opens its file pages without any check; the site's own player asks for one Cloudflare tap and needs SkyStream 2.9.0+.
- **Net77 / NetMirror** take about 40 seconds on the first play — that is the app's own session check, and the result is cached for later titles.
- **NetMirror** limits how often one connection may download. If you see *too many requests*, wait a minute and press Play again.
- **RareAnimes** plays from the site's Pixeldrain season packs; a few older posts only have Mega links, which can't be streamed.
- **ReelFren** — some of its apps (MovieBox, JoyReels, FlexTV, KalosTV, Vigloo) are currently not playing on reelfren.com itself, so the plugin says so instead of showing a broken video.
- **GDFlix / HubCloud** files (KatMovieHD, SSR Movies, KDramaMaza, PikaHD, KatDrama, Movies4u) play in the app; desktop tools may get a Cloudflare check on them.

## 🛠️ For developers

<details>
<summary><b>Repository layout, build and testing</b></summary>

<br>

```txt
<Plugin>/plugin.json   manifest: name, version, baseUrl, domains, authors
<Plugin>/plugin.js     the plugin (getHome, search, load, loadStreams)
AllInOne/              generated by tools/build-aio.mjs — do not edit by hand
tools/aio/core.js      the All-in-one merging layer (home rows, search, links)
tools/                 app-accurate test harness and helpers
relay/                 optional geo-pass Cloudflare Worker
dist/                  built by CI — do not edit by hand
```

```bash
npm i -g skystream-cli
skystream validate                                   # check every manifest and plugin
skystream test -p ReelFren -f search -q "billionaire"
cd tools && npm install && node app-harness.mjs ../ReelFren --auto --items 3
```

Pushing to `main` runs GitHub Actions, which rebuilds All-in-one (`node tools/build-aio.mjs` — it bumps All-in-one's version when any plugin changed), then `dist/plugins.json` and the plugin bundles. Bump `version` in `plugin.json` so the app offers the update.

</details>
